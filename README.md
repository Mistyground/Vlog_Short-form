# 둘집로그 — 계정 기획서

> 두 사람이 사는 작은 집을 **원상복구 가능한 방식으로** 고치고, 매일 쓰는 살림템을 **진짜로 써보고** 남기는 일상 브이로그 숏폼 계정

---

## 1. 계정 한 줄 정의

**"전셋집도 내 집처럼. 둘이 고쳐 쓰는 살림 기록"**

- 계정명(안): `@dulzip.log` (둘집로그). 대체안: `@two.salim`(두살림), `@ourroom.diary`(우리방일기)
- 프로필 소개 (3줄):
  ```
  둘이 사는 18평 전셋집 🏠
  원상복구 되는 인테리어 · 써보고 남긴 주방템
  📩 협찬/광고 문의 DM
  ```

### 왜 이 포지션인가
| 이유 | 설명 |
|---|---|
| **광고주 범위가 넓다** | 인테리어(조명·커튼·수납·가구) + 주방(조리도구·가전·식기) + 생활(세제·청소기)까지, 한 집 안에서 나오는 모든 제품이 광고 가능 영역 |
| **"전월세" 니치** | 자가 인테리어 계정은 많지만, 못 박지 않고·떼어낼 수 있는 인테리어는 2030 세입자 다수의 실제 고민이라 저장·공유가 잘 됨 |
| **두 사람 = 자연스러운 생활감** | 컵 두 개, 앞치마 두 벌, 손 두 쌍. 관계는 설명하지 않아도 "같이 사는 집"이라는 분위기만으로 신혼·동거·자취 타겟을 모두 끌어안음 |
| **얼굴 노출 최소화 가능** | 손·뒷모습·공간 위주 촬영으로 사생활 보호, 제품이 주인공이 되어 광고주가 선호하는 화면 구성 |

> 💡 관계 표현 원칙: "남자친구/남편" 같은 호칭은 쓰지 않고 **"같이 사는 사람", "옆사람", 혹은 닉네임**으로 부른다. 결혼 여부와 상관없이 계속 쓸 수 있는 세계관.

## 2. 타겟

| 구분 | 내용 |
|---|---|
| 메인 | 25~35세, 첫 독립·신혼·동거로 **처음 살림을 꾸리는** 사람 |
| 고민 | "전셋집이라 못 박기 무서움", "주방템 사면 결국 안 씀", "좁은 집 수납" |
| 행동 | 오늘의집·쿠팡·네이버 쇼핑에서 저장해두고 비교 후 구매 → **저장 수가 높은 콘텐츠**가 됨 |

---

## 3. 콘텐츠 기둥 (4개 고정 시리즈)

| # | 시리즈명 | 내용 | 연결되는 광고 카테고리 | 비율 |
|---|---|---|---|---|
| ① | **떼어내도 되는 인테리어** | 무타공 선반, 조명 교체, 시트지, 커튼레일, 러그 | 조명·수납·패브릭·소품 | 30% |
| ② | **써보고 남긴 주방템** | 1주일 써보고 "남김/버림" 판정 | 조리도구·소형가전·식기 | 30% |
| ③ | **둘이 차리는 한 끼** | 퇴근 후 20분 요리, 주말 브런치 | 냄비·팬·칼·식재료·밀키트 | 25% |
| ④ | **일요일 밤 리셋** | 주간 청소·정리 루틴, 냉장고 정리 | 청소기·세제·수납용기 | 15% |

→ 시리즈마다 **오프닝 컷과 자막 폰트를 고정**해서 "아 그 계정"으로 기억되게 만든다.

## 4. 촬영·편집 톤 가이드

- **비율**: 9:16 세로, 길이 15~30초 (정보형은 최대 45초)
- **촬영**: 고정 삼각대 + 손 클로즈업 위주, 자연광 오전/오후 4시대
- **소리**: ASMR(칼질·물소리·문 닫는 소리) + 잔잔한 BGM, 내레이션 대신 자막
- **색감**: 따뜻한 화이트·우드 톤 통일 (피드 그리드가 하나의 집처럼 보이게)
- **자막**: 1줄 최대 14자, 첫 화면 큰 자막 1개 + 하단 작은 정보 자막
- **반복 장치**: 매 영상 마지막 1초에 "컵 두 개를 내려놓는 소리" 시그니처 컷 → 브랜드 각인

## 5. 수익화 로드맵

| 단계 | 팔로워 | 목표 | 수익 경로 |
|---|---|---|---|
| **0단계** | 0 → 1천 | 3개월간 주 4회 업로드, 시리즈 포맷 검증 | 없음 (콘텐츠 자산 쌓기) |
| **1단계** | 1천 → 5천 | 저장율 높은 포맷 집중 | 쿠팡 파트너스·오늘의집 제휴 링크, 체험단(레뷰·리뷰노트 등) 지원 |
| **2단계** | 5천 → 1만 | 미디어킷 제작, 브랜드 DM 직접 제안 | 소형 리빙 브랜드 **제품 협찬** → 유료 협찬 전환 |
| **3단계** | 1만 → 5만 | "써보고 남긴" 시리즈를 신뢰 자산으로 | **유료 광고 릴스**, 브랜드 공동구매(공구), 인스타그램 제휴 콘텐츠 |
| **4단계** | 5만+ | 계정 = 큐레이션 브랜드 | 장기 앰버서더 계약, 자체 셀렉샵·PB 상품 |

### 협찬을 부르는 장치
1. **미디어킷** (1천 명부터 준비): 계정 소개, 타겟, 평균 조회·저장 수, 기존 협업 사례
2. **"남김/버림" 시리즈**: 솔직한 판정이 쌓일수록 "여기서 남김 받으면 팔린다"는 신뢰가 생김 → 광고 단가의 근거
3. **브랜드 태그 습관**: 내돈내산 제품도 브랜드 계정을 태그 → 브랜드 담당자에게 노출
4. **광고 표기 준수**: 협찬 시 영상 첫 화면·캡션 첫 줄에 `#광고` 또는 `#협찬` 명시 (공정위 추천·보증 심사지침). 신뢰가 곧 단가다.
