# 둘집로그 — 계정 기획서

> **15평 자가 오피스텔**을 "오피스텔 같지 않은 집"으로 바꾸고, 작은 주방에서 진짜로 써보고 남긴 살림템을 기록하는 두 사람의 일상 브이로그 숏폼 계정

---

## 1. 계정 한 줄 정의

**"오피스텔도 집이 된다. 15평에 둘이 사는 살림 기록"**

- 계정명(안): `@dulzip.log` (둘집로그). 닉네임 후보 13개와 추천 TOP 3는 [`docs/account_names.md`](docs/account_names.md) 참고
- 프로필 소개 (3줄):
  ```
  15평 오피스텔, 둘이 사는 진짜 집 🏠
  15평 회의 · 써보고 솔직 판정 · 2구 주방
  📩 협찬/광고 문의 DM
  ```

### 왜 이 포지션인가
| 이유 | 설명 |
|---|---|
| **"오피스텔 인테리어"는 수요가 크다** | 2030 1~2인 가구 상당수가 오피스텔에 살지만, 하얀 벽·매립등·빌트인 가전 때문에 "숙소 같다"는 불만이 공통적. **"오피스텔 느낌 지우기"**는 그 자체로 검색되고 저장되는 주제 |
| **자가라서 시공까지 가능** | 세입자 계정은 소품까지만 다룰 수 있지만, 자가는 **조명 공사·필름·붙박이장·주방 상판 교체**까지 가능 → 시공업체·가구·가전처럼 **단가가 큰 광고주**로 확장 가능 |
| **작은 주방 = 주방템 광고의 최적 무대** | 2구 인덕션·좁은 조리대·작은 빌트인 냉장고. "이 좁은 데서도 쓸모 있나?"를 검증하는 콘텐츠는 소형가전·수납용기·조리도구 브랜드가 가장 원하는 화면 |
| **15평 = 둘이 살기 딱 빠듯한 크기** | 1인 오피스텔 계정과 차별화. 두 사람 짐을 15평에 넣는 수납·동선 이야기가 신혼·동거·자취 타겟 모두에게 "내 얘기" |
| **두 사람, 관계 설명 없이** | 컵 두 개, 손 두 쌍. "같이 사는 집"이라는 분위기만으로 충분 |
| **얼굴 노출 최소화 가능** | 손·뒷모습·공간 위주 촬영 → 사생활 보호 + 제품이 주인공인 화면 |

> 💡 관계 표현 원칙: "남자친구/남편" 같은 호칭은 쓰지 않고 **"같이 사는 사람", "옆사람", 혹은 닉네임**으로 부른다. 결혼 여부와 상관없이 계속 쓸 수 있는 세계관.

## 3. 콘텐츠 방향: "15평 회의" (v2, 사전조사 기반)

> 근거: [`docs/research.md`](docs/research.md). 예쁜 집 자랑이 아니라 **현실 15평에 둘이 사는 진짜 생활**을 보여주고, 좁은 집의 문제를 둘이 회의하듯 풀어간다.

| # | 시리즈 | 포맷 | 근거 사례 | 연결되는 광고 카테고리 | 비율 |
|---|---|---|---|---|---|
| A | **15평 문제 해결** | 문제 → 0원·저가 해결 → 결과 (가구 배치, 다이소 해킹, 무타공 떼어보기) | 공간베어 583만·779만 회, 다이소 압축봉 1,117만 회 | 가구·수납·무타공 | 30% |
| B | **솔직 판정** | 시연 → 단점 → 남김/버림 | #deinfluencing, 소개팁 | 조리도구·소형가전 | 25% |
| C | **우리 집은 이렇게 해** | 둘의 살림 방식 차이 → "너네 집은?" | 식기세척기 논쟁 200만 회 | 세제·패브릭·주방소품 | 20% |
| D | **2구 챌린지** | 2구·시간·금액 제한 요리 | 김생못 940만, 욜로리아 470만 회 | 팬·냄비·식품·밀키트 | 15% |
| E | **현실 리셋 / 15평 회의** | 어질러진 진짜 집 리셋, 이번 달 살 것 투표 | "평범한 집 투어", 밸런스 게임 | 청소가전·살림 자동화 | 10% |

### 콘텐츠에서 지키는 원칙
- **"자가"는 말하지 않는다.** 자가는 시공 협찬을 받을 수 있는 내부 강점일 뿐, 화면에서는 "15평에 둘이 산다"는 현실감만 보여준다 (자랑으로 읽히면 반감)
- **과장된 before/after, 쇼룸 같은 연출 금지.** 실패와 어질러진 모습을 그대로
- **분노 유도·성별 갈등 금지.** 실수는 "귀여운 실수"까지만

## 4. 촬영·편집 톤 가이드

- **비율**: 9:16 세로, 길이 20~40초 (오래 성과를 내는 리뷰 영상은 40초 이상이라는 대행사 분석이 있어 판정 회차는 길게)
- **시그니처 오프닝**: 나무 주걱으로 도마 "탕탕" + **"15평 회의, 시작합니다"** (매 회 고정, 밈이 되도록)
- **목소리 출연**: 얼굴 없이 손·뒷모습 + **실제 대화 녹음**. 한 명은 진행, 한 명은 짧고 무심한 리액션 (캐릭터 대비)
- **첫 화면 숫자**: 평수·인원·예산·시간 중 하나 이상을 첫 자막에
- **시연 우선**: 무게·세척·크기·실측값을 화면으로. "좋아요"라는 말 대신 증명
- **촬영**: 고정 삼각대 + 손 클로즈업. 15평은 광각이면 오히려 좁아 보이므로 부분 클로즈업 위주
- **엔딩**: 질문·투표 + 컵 두 개 내려놓는 소리
- **CTA**: "○○ 댓글 → DM으로 제품 정보", "같이 사는 사람한테 보내기" (릴스 캡션 링크는 클릭이 안 되므로)

## 5. 수익화 로드맵

| 단계 | 팔로워 | 목표 | 수익 경로 |
|---|---|---|---|
| **0단계** | 0 → 1천 | 3개월간 주 4회 업로드, 시리즈 포맷 검증 | 없음 (콘텐츠 자산 쌓기) |
| **1단계** | 1천 → 5천 | 저장율 높은 포맷 집중 | 쿠팡 파트너스·오늘의집 제휴 링크, 체험단(레뷰·리뷰노트 등) 지원 |
| **2단계** | 5천 → 1만 | 미디어킷 제작, 브랜드 DM 직접 제안 | 소형 리빙 브랜드 **제품 협찬** → 유료 협찬 전환 |
| **3단계** | 1만 → 5만 | "남김/버림" 시리즈를 신뢰 자산으로 | **유료 광고 릴스**, 브랜드 공동구매(공구), 인스타그램 제휴 콘텐츠, **시공·가구 협찬** (자가 오피스텔 강점) |
| **4단계** | 5만+ | 계정 = 오피스텔 인테리어 큐레이션 브랜드 | 장기 앰버서더 계약, 오피스텔 인테리어 가이드(전자책·클래스), 자체 셀렉샵·PB 상품 |

### 자가 오피스텔이라서 가능한 추가 수익
- **시공 협찬**: 필름·조명·도배·주방 상판 업체는 "실거주 before/after" 콘텐츠를 원함. 자가라 공사 허락을 받을 필요가 없음
- **오늘의집 집들이**: 15평 오피스텔 집들이는 조회 수가 높은 편이라, 공간이 완성되면 집들이 글로 계정 유입 통로를 하나 더 만들 수 있음
- **오피스텔 맞춤 정보 상품**: "15평 오피스텔 가구 배치 도면", "2구 주방 필수템 리스트" 같은 콘텐츠를 나중에 가이드 상품으로 묶을 수 있음

### 협찬을 부르는 장치
1. **미디어킷** (1천 명부터 준비): 계정 소개, 타겟, 평균 조회·저장 수, 기존 협업 사례, **집 평면도와 공간 사진** (광고주가 제품이 어디에 놓일지 상상할 수 있게)
2. **"남김/버림" 시리즈**: 솔직한 판정이 쌓일수록 "여기서 남김 받으면 팔린다"는 신뢰가 생김 → 광고 단가의 근거
3. **브랜드 태그 습관**: 내돈내산 제품도 브랜드 계정을 태그 → 브랜드 담당자에게 노출
4. **광고 표기 준수**: 협찬 시 영상 첫 화면·캡션 첫 줄에 `#광고` 또는 `#협찬` 명시 (공정위 추천·보증 심사지침). 신뢰가 곧 단가다.
