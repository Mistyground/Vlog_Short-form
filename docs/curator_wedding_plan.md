# 큐레이터 수익 & 결혼 협찬 플랜

> 수익화 단계(README 5장)는 그대로 유지하고, 그 안에서 **큐레이터 링크 수익**과 **나중의 결혼 협찬**을 어떻게 끼워 넣을지 정리한 문서입니다.
> 수수료와 조건은 2025~2026년 공개 자료 기준이며 자주 바뀝니다. **가입 전에 각 공식 페이지에서 꼭 다시 확인하세요.**

# 1부. 큐레이터 링크 수익

## 1. 플랫폼 5곳 한눈에

## 2. 시리즈별로 어떤 링크를 거나

| 시리즈 | 주로 거는 링크 | 예시 |
|---|---|---|
| A. 15평 문제 해결 | 오늘의집 / 쿠팡 | 책장·무타공 선반 → 오늘의집, 다이소류 대체품 → 쿠팡 |
| B. 솔직 판정 | 오늘의집 / 29CM | 프라이팬·소형가전 → 오늘의집, 식기 → 29CM |
| C. 우리 집은 이렇게 해 | 쿠팡 / 29CM / 올리브영 | 세제·수세미 → 쿠팡, 수건·패브릭 → 29CM, 치약·바디워시 "우리 집은 뭐 써?" → 올리브영 |
| D. 3구 챌린지 | 쿠팡 / 29CM | 재료 → 쿠팡, 그릇·팬 → 29CM |
| E. 현실 리셋 / 15평 회의 | 오늘의집 / 무신사 / 올리브영 | 청소가전 → 오늘의집, 홈웨어·실내화 → 무신사, 리셋 마무리 디퓨저·향초 → 올리브영 |

> 같은 제품이 여러 플랫폼에 있으면 **수수료가 높은 곳보다 시청자에게 싼 곳**을 건다. 한 번이라도 "비싼 링크를 걸었다"는 댓글이 달리면 솔직 판정 계정의 신뢰가 무너진다.

### 올리브영을 살리는 새 회차 아이디어
우리 계정은 집·주방 중심이라 올리브영 상품이 자연스럽게 나오는 자리를 따로 만듭니다.

| 회차 | 포맷 | 훅 / 카피 |
|---|---|---|
| 15평 욕실 선반, 두 사람 것 다 올라갈까? | A. 문제 해결 | 숫자: "선반 1칸, 두 사람 세면도구 14개" |
| 치약 짜는 법, 우리 집은 반반 | C. 우리 집은 이렇게 해 | 인지부조화: 같은 치약, 가운데 vs 끝부터 |
| 리셋 마지막 5분, 집 냄새 바꾸기 | E. 현실 리셋 | EP.05 엔딩에 디퓨저·향초 1컷 추가 |
| 사지 마세요: 좁은 욕실에 대용량 펌프 | B. 솔직 판정 | 금지형 + 실측 |

## 3. 링크 동선 (릴스는 캡션 링크가 안 눌림)

```
릴스 엔딩: "○○ 댓글 달면 링크 보내드려요"
      ↓
DM 자동 발송 (키워드별 링크 1개)
      ↓
프로필 링크 1개 = 링크 모음 페이지 "15평 회의 장바구니"
   ├─ 이번 달 회의에서 산 1개
   ├─ 남김 판정 받은 것들 (시리즈별)
   ├─ 오늘의집 큐레이터 샵
   ├─ 29CM 큐레이션 샵
   └─ 올리브영 "우리 집 욕실·향" 모음
```

- **"15평 회의 장바구니"**가 큐레이터 브랜드의 핵심. 남김 판정 받은 물건만 들어간다는 규칙 하나가 곧 신뢰
- 29CM·오늘의집은 **큐레이션 샵**을 만들 수 있으니, 링크 모음 페이지에서 샵으로 보내는 구조가 좋음
- 매달 EP.10 "이번 달 살 것 1개"를 장바구니 갱신과 연결 → 월 1회 링크 업데이트 루틴

## 4. 표기 규칙 (제휴 링크도 광고)
- 제휴 링크로 수수료를 받는 것도 경제적 이해관계라 **표기 대상**입니다 (공정위 추천·보증 심사지침)
- 캡션 첫 줄 또는 영상 안: `이 링크로 구매하면 수수료를 받을 수 있어요`
- DM 자동 발송 메시지에도 같은 문구
- 댓글에만 적는 표기는 인정되지 않는다는 해석이 있음 [6]

## 5. 단계별 실행
| 시점 | 할 일 |
|---|---|
| 지금 | 오늘의집·29CM·**올리브영** 큐레이터 가입 (바로 시작 가능한 곳부터), 쿠팡 파트너스 가입 |
| 무신사 | 사전 승인제라 **릴스 20~30개가 쌓이고 계정 성격이 보일 때** 신청 |
| 1천 명 | DM 자동 발송 툴 연결, "15평 회의 장바구니" 링크 모음 페이지 오픈 |
| 매달 | 플랫폼별 클릭·구매 수 기록 → 어떤 시리즈가 어떤 플랫폼에서 팔리는지 파악 → 미디어킷 숫자로 사용 |

# 2부. 나중에 결혼할 때 협찬 받기

## 1. 핵심 아이디어: 결혼 발표가 계정 최대의 "반전"
지금은 관계를 말하지 않고 "옆사람", 손 두 쌍, 컵 두 개로만 보여줍니다. 그래서 나중에 결혼을 발표하는 순간이 **수백 편 동안 쌓아온 이야기의 반전**이 됩니다.

> **"15평 회의, 시작합니다. 오늘 안건은… 결혼입니다."**

- **훅**: 평소와 똑같은 오프닝(탕탕)인데 안건 카드가 다름 → 인지부조화
- **반전**: 늘 보던 컵 두 개 옆에 반지 두 개
- **결말 = 미러링**: EP.01과 같은 평면도 장면으로 돌아가 "이제 이 15평에 혼수를 넣어야 함" → 동시에 클리프행어로 혼수 시리즈 예고

발표할지, 언제 할지는 **전적으로 두 분이 정하면 됩니다.** 이 계정은 결혼 여부와 상관없이 굴러가도록 설계되어 있고, 발표를 하면 협찬 기회가 하나 더 열리는 구조입니다.

## 2. 우리만의 차별점: "15평 혼수 회의"
일반 웨딩 계정은 "큰 냉장고, 큰 소파"를 보여줍니다. 우리는 **15평이라 못 들이는 혼수**가 이야기의 중심입니다.

| 회차 아이디어 | 포맷 | 협찬 카테고리 |
|---|---|---|
| 15평에 혼수 냉장고 들어갈까? (줄자 실측) | A. 문제 해결 | 냉장고·소형가전 |
| 식세기 vs 3구 주방 조리대, 15평 혼수 회의 | E. 15평 회의 + 투표 | 식기세척기 |
| 혼수 식기 세트 대신 "2인분만" 사기 | B. 솔직 판정 | 식기·커트러리 |
| 신혼 침구, 15평 수납에 들어가는 것만 | A. 문제 해결 | 침구·패브릭 |
| 청첩장·답례품도 15평 회의로 | E. 투표 | 청첩장·답례품·디저트 |
| 결혼 전 100일 "둘이 같이 하는 관리 루틴" (욕실 선반 그대로) | C. 우리 집은 이렇게 해 | 스킨케어·바디케어 (올리브영 큐레이터 링크와 연결) |
| 둘이 처음 맞춘 머그 → 결혼 머그 | 미러링 (EP.10 컵 두 개 회수) | 식기·커스텀 굿즈 |

→ "작은 집 신혼"은 소형가전·소형가구 브랜드가 원하는 정확한 타겟이라 협찬 궁합이 좋습니다.

## 3. 결혼 협찬을 받기 위해 지금부터 할 일
| 시점 | 할 일 |
|---|---|
| 지금 ~ 결혼 1년 전 | 계정을 키우면서 **판정 회차를 꾸준히 쌓기**. 혼수 브랜드는 "이 계정의 판정을 사람들이 믿는가"를 봄 |
| 결혼 6~12개월 전 `[일반 지식]` | 미디어킷에 "웨딩 시즌 콘텐츠 계획" 추가 → 가전·가구·식기·침구 브랜드에 먼저 제안. 브랜드 캠페인은 몇 달 전에 기획되는 경우가 많음 |
| 발표 직후 | 발표 회차의 조회·댓글 수치를 바로 미디어킷에 반영 (반응이 가장 클 때가 협상력이 가장 높을 때) |
| 결혼 후 | "15평 신혼" 시리즈로 연결 → 장기 앰버서더(4단계)로 가는 다리 |

## 4. 결혼 협찬 주의점
- **광고 표기는 동일하게.** 혼수 협찬도 첫 화면 `#광고`. 결혼이라는 감성 콘텐츠일수록 뒷광고 논란 피해가 큼
- **협찬이어도 판정 구조 유지.** 단점 1개 이상, 실측. 결혼 시즌에만 칭찬 일색이면 쌓아온 신뢰를 한 번에 씀
- **계약서 확인** `[일반 지식]`: 의무 업로드 수, 콘텐츠 2차 활용 기간(브랜드 광고로 돌리는지), 제품 반납 여부, 위약 조건
- **세금** `[일반 지식]`: 협찬 물품·원고료도 소득으로 볼 수 있으니 규모가 커지면 세무 상담 권장
- **사생활 경계**: 결혼식 장소·날짜·가족 얼굴은 공개 범위를 미리 정해두기 (지금처럼 손·뒷모습 원칙 유지 가능)
