모든 대본은 아래 원칙을 적용했습니다.

| 원칙 | 선택지 |
|---|---|
| **첫 3초 훅** | 인지부조화 / 시각적 충격 / 자이가르니크 효과 |

## EP.01 오피스텔 느낌, 조명 하나로 지우기 `① 오피스텔 느낌 지우기`

**첫 화면 자막:** "오피스텔 사는 분들, 집이 숙소 같은 이유 이거예요"
**카피 기술:** 타겟 지목 → 오피스텔 거주자라면 "내 얘기"라서 손가락이 멈춤

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 하얀 매립등 아래 차갑게 뜬 거실 → 1프레임만 완성된 따뜻한 조명 거실이 번쩍 | "오피스텔 사는 분들, 집이 숙소 같은 이유 이거예요" |
| 3~12초 | 천장 매립등 클로즈업, 레일 조명 박스 개봉, 사다리 세팅 | "천장 공사 각오하고 시작" |
| 12~18초 **반전** | 사다리에 올라가려는 순간 옆사람이 멈춰 세움 → 매립등은 끄고 스탠드 2개 + 상부장 아래 간접조명만 켬 | "근데 사실 천장은 손도 안 댔어요" |
| 18~25초 **결말** | 같은 거실, 같은 시간대. 조명 높이만 낮췄을 뿐인데 완전히 다른 저녁 | 컵 두 개 내려놓는 소리 |

- **훅 = 자이가르니크 효과**: 완성본을 0.3초만 보여주고 다시 before로 돌아가면, 뇌가 "그 완성본"을 다시 보려고 끝까지 시청함. 비포·애프터가 핵심인 인테리어에 가장 잘 맞는 훅.
- **결말 = 카타르시스**: "오피스텔이라 어쩔 수 없다"는 체념을 조명 높이 하나로 해결. 첫 편은 문제 해결형으로 끝내야 계정의 쓸모가 각인됨.
- **반전**: 천장 공사인 줄 알았는데 실은 스탠드와 간접조명. 난이도가 확 낮아지면서 "나도 할 수 있겠다"는 저장 욕구로 이어짐. (자가라서 실제 레일 공사는 시즌 1 "오피스텔 탈출 프로젝트"에서 따로 연재하면 됨.)
## EP.02 실리콘 주걱 1주일 써보기 `② 2구 주방 살림템`

**첫 화면 자막:** "주걱 사기 전에 이거 먼저 하지 마세요"
**카피 기술:** 금지형 → 다들 하는 걸 하지 말라니 뇌가 반응함

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 새하얀 주걱으로 토마토소스를 크게 휘저음 | "주걱 사기 전에 이거 먼저 하지 마세요" |
| 3~15초 | Day1~Day7 컷 전환 (카레, 볶음밥, 계란), 좁은 수저통에 꽂히는 크기인지도 체크 | 일차별 작은 자막 |
| 15~20초 **반전** | Day7, 다른 브랜드 주걱은 주황색으로 물들었는데 이 주걱은 그대로 | "물든 건 원래 쓰던 거였어요" |
| 20~25초 **결말** | 판정 도장 쾅 | **남김 ✅** |

- **훅 = 시각적 충격**: 흰색 + 빨간 소스라는 강한 색 대비만으로 바로 시선이 감. 주방템 리뷰는 말보다 색 대비가 직관적임.
- **결말 = 카타르시스**: "물들까?"라는 걱정을 판정 도장으로 확실히 해소. 시리즈 전체의 시그니처가 될 엔딩.
- **반전**: 이염된 쪽이 테스트 제품이 아니라 원래 쓰던 주걱. 예상을 뒤집으면서 동시에 제품 장점을 증명함.

## EP.03 2구 인덕션, 퇴근 후 20분, 계란 3개로 만드는 저녁 `③ 2구로 차리는 한 끼`

**첫 화면 자막:** "계란 3개로 호텔 조식 같은 저녁"
**카피 기술:** 숫자와 구체성 → '3개', '20분'이라는 숫자가 진짜처럼 느끼게 함

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 완벽한 오믈렛 위로 칼이 들어가는 순간에서 정지 | "계란 3개로 호텔 조식 같은 저녁" |
| 3~15초 | 타이머 20:00 시작, 좁은 조리대에서 손 두 쌍이 각자 재료 손질, 2구 인덕션 양쪽 동시 가동 | 칼질·지글지글 ASMR |
| 15~19초 **반전** | 오믈렛 뒤집다가 찢어짐 | "...망했다" → 옆사람이 스크램블로 바꿔서 접시에 담음 |
| 19~26초 **결말** | 0~3초와 같은 각도, 같은 칼 들어가는 컷. 단, 스크램블 플레이트 | "계란 3개로 호텔 조식 같은 저녁" (첫 자막 그대로) |

- **훅 = 자이가르니크 효과**: 칼이 들어가는 순간에서 끊어 "안이 어떻게 생겼지?"를 남김.
- **결말 = 미러링**: 처음과 같은 컷·같은 자막으로 끝나지만, 실패 과정을 본 뒤라 "완벽하지 않아도 둘이면 된다"로 다르게 읽힘. 생활감·관계감을 말없이 전달.
- **반전**: 완벽한 요리 영상인 줄 알았는데 실패. 공감 댓글이 가장 많이 달리는 구간.

## EP.04 15평 일요일 밤 15분 리셋 `④ 15평 리셋`

**첫 화면 자막:** "월요일이 무서운 분들, 일요일 밤 15분만 쓰세요"
**카피 기술:** 타겟 지목 + 숫자

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 깨끗한 집 사이로 소파 위 빨래더미만 정확히 반 가려진 채 블러 처리 | "월요일이 무서운 분들" |
| 3~18초 | 15분 타이머 배속: 설거지 → 빨래 개기 → 바닥 → 냉장고 | 체크리스트 자막 |
| 18~22초 **반전** | 화면이 줌아웃되며 사실 둘이 **동시에** 하고 있었음이 드러남 (분할화면) | "혼자 하면 30분, 둘이 하면 15분" |
| 22~27초 **결말** | 불 끄기 → 다음 주 일요일 냉장고 문이 열리다 멈춤 | "다음 주엔 빌트인 냉장고 정리 편" |

- **훅 = 자이가르니크 효과**: 블러로 가린 미완성 공간이 "다 치워진 모습"을 보고 싶게 만듦.
- **결말 = 클리프행어**: 다음 에피소드를 예고해 **팔로우 이유**를 만듦. 루틴 시리즈는 연속성이 핵심이라 클리프행어가 적합.
- **반전**: 한 사람 루틴인 줄 알았는데 두 사람의 분업. 관계를 말하지 않고도 "같이 사는 집"을 보여주는 장치.

## EP.05 15평에 두 사람 짐, 수납장 안 사고 넣기 `④ 15평 리셋`

**첫 화면 자막:** "좁은 집에 수납장 더 사지 마세요"
**카피 기술:** 금지형 → 좁으면 수납장을 사는 게 상식이라, 하지 말라니 뇌가 반응함

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 장바구니에 담긴 수납장 결제 버튼을 누르려는 손을 다른 손이 탁 막음 | "좁은 집에 수납장 더 사지 마세요" |
| 3~14초 | 붙박이장 문을 열면 꽉 찬 두 사람 옷 → 침대 밑·현관 신발장 위·세탁기 위 빈 공간 체크 | "15평의 숨은 공간 4곳" |
| 14~18초 **반전** | 다 정리한 줄 알았는데 붙박이장 문이 안 닫힘 | "...안 닫힘" → 옆사람이 계절 지난 옷을 압축팩에 넣어 침대 밑으로 |
| 18~24초 **결말** | 붙박이장 문이 "딸깍" 한 번에 닫힘, 장바구니에서 수납장 삭제 | "수납장 값 아낌" |

- **훅 = 인지부조화**: "좁은 집"과 "수납장 사지 마라"라는 상식과 반대되는 개념을 붙여 궁금하게 만듦.
- **결말 = 카타르시스**: 안 닫히던 문이 닫히는 소리 하나로 문제를 완벽히 해결. 정리 콘텐츠는 이 쾌감이 저장을 부름.
- **반전**: 끝난 줄 알았는데 문이 안 닫힘 → 두 사람의 협업으로 해결. 15평에 둘이 산다는 설정을 자연스럽게 보여줌.
## EP.06 "이거 사지 마세요" 1주일 써보고 버린 템 `② 2구 주방 살림템`

**첫 화면 자막:** "오피스텔 필수템이라길래 샀는데"
**카피 기술:** 스토리텔링 → 광고 같은 리뷰가 아니라 "속은 경험"이라는 관점

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 귀여운 미니 와플메이커 → 바로 쓰레기봉투 옆에 놓인 컷 | "오피스텔 필수템이라길래 샀는데" |
| 3~16초 | 사용 Day1(신남) → Day3(세척 귀찮음) → Day7(서랍행) | |
| 16~20초 **반전** | 버리려다 옆사람이 꺼내서 냉동 크루아상 굽기 | "근데 용도를 바꾸니까?" |
| 20~26초 **결말** | 판정 도장이 '버림'에서 '남김'으로 바뀜 | **남김 ✅ (단, 크루아상용)** |

- **훅 = 인지부조화**: '필수템'과 '쓰레기통'이라는 상반된 이미지를 한 화면에.
- **결말 = 카타르시스**: 쓸모없던 템의 쓸모를 찾아줌. 솔직함 + 해결로 신뢰를 쌓는 회차.
- **반전**: 버림 판정이 뒤집힘. "남김/버림" 시리즈가 단순 리뷰가 아니라는 걸 보여줌.

> 이 회차는 광고주에게도 중요: 솔직한 "버림"이 있어야 "남김"이 믿을 만해진다.

## EP.07 5만 원으로 침대 안 보이게 공간 분리 `① 오피스텔 느낌 지우기`

**첫 화면 자막:** "현관 열자마자 침대 보이는 오피스텔, 5만 원이면 됩니다"
**카피 기술:** 타겟 지목 + 숫자와 구체성

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 완전히 깜깜한 화면 → 현관 도어락 소리 → 불이 켜지자 정면에 침대가 그대로 보이는 before | "현관 열자마자 침대 보이는 오피스텔" |
| 3~16초 | 천장 커튼(린넨) 설치 → 낮은 책장으로 경계 만들기 → 침대 쪽 무드등, 남은 금액 카운터 | "남은 돈 50,000 → 7,000" |
| 16~20초 **반전** | 영상이 가로 화면처럼 레터박스가 생김 → 폰을 돌리는 손이 보이며 사실 세로 | "침대에 누워서 보는 시점" (커튼 너머 거실이 안 보임) |
| 20~26초 **결말** | 0~3초와 같은 도어락 소리, 같은 깜깜한 화면 → 불이 켜지면 이번엔 커튼과 거실만 보임 | "현관 열자마자 침대 보이는 오피스텔" (첫 자막에 취소선) |

- **훅 = 시각적 충격**: 완전 검은 화면은 피드에서 오히려 튐. 도어락 소리로 "집에 들어오는 순간"에 시청자를 세움.
- **결말 = 미러링**: 같은 소리·같은 앵글이 끝에선 "분리된 집"으로 완전히 다르게 읽힘. 오피스텔 공간 분리는 before/after 대비가 핵심이라 미러링이 가장 강함.
- **반전**: 가로 영상인 줄 알았는데 세로(누운 시점). 사용자 원칙 예시를 그대로 살린 회차.
## EP.08 일식집 주방장 출신 아빠가 알려준 칼 관리법 `③ 2구로 차리는 한 끼`

**첫 화면 자막:** "칼 쓰고 바로 씻지 마세요"
**카피 기술:** 금지형 + 스토리텔링 (가족에게 배운 레시피·노하우 관점. 실제 가족 중 요리 경력자가 있다면 그 이야기로 교체, 없다면 "할머니가 알려준" 등 진짜 이야기만 사용)

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 토마토가 칼에 짓눌려 터지는 슬로우 | "칼 쓰고 바로 씻지 마세요" |
| 3~15초 | 휴대폰 메모에 적힌 가족의 손글씨 사진 → 순서대로 따라 함 | 메모 내용 자막 |
| 15~19초 **반전** | 메모 마지막 줄 클로즈업 | "근데 제일 중요한 건 칼이 아니었음" |
| 19~25초 **결말** | 메모 마지막 줄은 블러, 도마 위 완벽한 토마토 슬라이스 | "마지막 줄은 다음 편에" |

- **훅 = 시각적 충격**: 터지는 토마토 슬로우는 0.5초 만에 이해되는 강한 자극.
- **결말 = 클리프행어**: 마지막 줄을 가려 2편 시청과 팔로우를 유도. 스토리형 콘텐츠는 연재가 강함.
- **반전**: 칼 관리 팁인 줄 알았는데 핵심은 다른 데 있음. 정보형 → 스토리형으로 꺾기.

## EP.09 오피스텔 빌트인 냉장고, 반찬통 하나 바꿨을 뿐인데 `④ 15평 리셋`

**첫 화면 자막:** "냉장고 열 때마다 한숨 쉬는 분들"
**카피 기술:** 타겟 지목

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | 냉장고 문이 반만 열린 채로 정지 (안이 반만 보임) | "냉장고 열 때마다 한숨 쉬는 분들" |
| 3~16초 | 전부 꺼내기 → 유통기한 체크 → 같은 규격 용기로 통일 | 용기 딸깍 ASMR |
| 16~20초 **반전** | 완성된 줄 알았는데 문 쪽 칸이 아직 엉망 | "아 여기 남았다" → 옆사람이 이미 정리해둔 채 엄지 |
| 20~26초 **결말** | 0~3초와 같은 각도로 문이 끝까지 열림 | 한숨 대신 "오" 소리 |

- **훅 = 자이가르니크 효과**: 반만 열린 문이 전체를 보고 싶게 만듦.
- **결말 = 카타르시스** (+ 미러링 구도): 정리 전후의 대비로 시원하게 해결. 정리 콘텐츠는 카타르시스가 최대 무기.
- **반전**: 다 끝난 줄 알았는데 남은 칸 → 이미 해결돼 있음. 두 사람 구도를 재확인.
- 연결: EP.04 클리프행어의 회수 편.

## EP.10 계정 시작 100일, 우리 오피스텔은 이렇게 바뀌었다 `계정 기념 회차 (3개월 차 업로드)`

**첫 화면 자막:** "100일 동안 15평에서 바뀐 것"
**카피 기술:** 숫자 + 스토리텔링

| 구간 | 화면 | 자막 / 소리 |
|---|---|---|
| 0~3초 **훅** | EP.01 첫 장면(차가운 매립등 거실)과 같은 자리의 현재 거실로 0.5초 플래시 | "100일 동안 15평에서 바뀐 것" |
| 3~16초 | EP.01~09의 before → after 빠른 몽타주 | 각 회차 판정 도장 연속 |
| 16~20초 **반전** | "가장 많이 바뀐 건" → 공간이 아니라 컵 두 개 (처음엔 짝 안 맞는 컵, 지금은 맞춘 머그) | |
| 20~26초 **결말** | EP.01과 같은 앵글로 돌아와 천장 매립등 클로즈업 → 사다리를 펼치는 손 | "다음 100일: 오피스텔 탈출 프로젝트" |

- **훅 = 자이가르니크 효과**: 미래의 완성본을 섬광처럼 먼저 보여줌.
- **결말 = 미러링 + 클리프행어**: 첫 회와 같은 앵글로 돌아와 성장을 체감시키고, EP.01에서 손대지 않았던 천장을 이번엔 진짜 공사한다는 예고로 시즌 2(자가 시공 연재)를 연다.
- **반전**: 인테리어 변화 회고인 줄 알았는데 진짜 변화는 "같이 사는 생활". 계정 세계관을 정리하는 회차.
