## 새 방향 요약: "15평 회의"

**현실 15평에 둘이 사는 진짜 생활.** 예쁜 집 자랑이 아니라 좁은 집의 문제를 둘이 회의하듯 풀고, 써본 물건은 시연으로 솔직하게 판정합니다.

### 모든 회차 공통 장치
| 장치 | 내용 | 근거 |
|---|---|---|
| **시그니처 오프닝** | 나무 주걱으로 도마를 "탕탕" + 목소리: **"15평 회의, 시작합니다"** | 쑤의 반복 멘트가 밈이 된 사례 |
| **목소리 출연** | 얼굴 없이 손·뒷모습 + **실제 대화 녹음**. 한 명은 진행, 한 명은 짧고 무심한 리액션 | 인생 녹음 중(얼굴 없이 102만), 하뉴의 대비 캐릭터 |
| **숫자 첫 화면** | 평수·인원·예산·시간 중 1개 이상을 첫 자막에 | 공간베어, 욜로리아, 서툴러도 괜찮아 |
| **시연 우선** | 말로 "좋아요" 대신 무게·세척·크기를 화면으로 | 원포인트(브랜드 선정 기준) |
| **질문·투표 엔딩** | "너네 집은?", "A vs B 댓글로" | 식기세척기 논쟁, Couple Joy |
| **DM 키워드 CTA** | "○○ 댓글 달면 제품 정보 보내드려요" + "같이 사는 사람한테 보내기" | 공구 DM 구조, sends 신호 |
| **시그니처 엔딩** | 컵 두 개 내려놓는 소리 | 기존 유지 |

### 하지 않는 것
- "자가", "우리 집 샀어요" 언급 (자랑으로 읽힘)
- 쇼룸처럼 꾸민 화면, 과장된 before/after 한 방 공개
- 음식 낭비·위생 문제로 분노 유도, 한쪽을 깎아내리는 갈등 연출
- 광고 표기를 '더보기'에만 넣기

## EP.01 15평에 둘이 사는데, 가구 위치만 바꿨어요 `A. 15평 문제 해결`
**[근거]** 공간베어 「두명이 사는 원룸 꾸미기」 583만 회, 「방이 넓어지는 가구배치법」 779만 회

**첫 화면 자막:** "15평 둘이 사는 집, 가구 위치만 바꿨어요"
**카피 기술:** 숫자와 구체성 (15평, 둘, 돈 0원)

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 종이에 그린 평면도가 **반만** 그려진 채 멈춤, 가구 스티커 손에 들려 있음 | 탕탕 "15평 회의, 시작합니다" / 자막: "15평 둘이 사는 집, 가구 위치만 바꿨어요" |
| 3~12초 | 현재 배치 문제 3개: 현관에서 침대 보임, 책상 둘이 한쪽에 몰림, 동선이 겹쳐 부딪힘 | 실제 대화: "여기서 매일 부딪혀" "응" |
| 12~17초 **반전** | 계획대로 침대를 돌리는데 **안 들어감** (벽에 걸림) | "...안 들어가는데?" (2초 정적) |
| 17~25초 **결말** | 침대를 90도가 아니라 **벽에 붙이는 대신 책장으로 가림** → 평면도 완성, 실제 공간 투어 | "돈 쓴 거: 0원" + 컵 두 개 소리 |

- **훅 = 자이가르니크 효과**: 반만 그려진 평면도가 완성본을 보고 싶게 만듦. 공간베어류 배치 콘텐츠의 핵심 궁금증("어떻게 바꿨지?")을 시각화.
- **결말 = 카타르시스**: 실패 후에 더 나은 해결책이 나오고 "0원"으로 마무리. 돈 안 드는 해결이 가장 크게 퍼졌다는 데이터와 일치.
- **반전**: 계획이 틀어지는 순간. 연출 없는 실패가 "진짜 생활" 신뢰를 만듦.
- **댓글·CTA**: "우리 집 평면도도 봐줄 사람?" / **"도면" 댓글 → 평면도 이미지 DM**
- **협찬 연결**: 책장·수납가구 브랜드

## EP.02 설거지, 컵 먼저 vs 접시 먼저 `C. 우리 집은 이렇게 해`
**[근거]** @its.carmelajoy 식기세척기 영상 이틀 만에 약 200만 회, "우리 집은…" 비교 댓글 폭발

**첫 화면 자막:** "같은 싱크대, 정반대 설거지"
**카피 기술:** 타겟 지목의 변형 ("우리 집은 어떻지?"를 바로 떠올리게 함)

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 분할 화면: 같은 싱크대, A는 컵부터, B는 기름 프라이팬부터 | 탕탕 "15평 회의, 시작합니다" / 자막: "같은 싱크대, 정반대 설거지" |
| 3~14초 | 각자 이유 설명 (실제 대화). A: "깨끗한 것부터 해야 물이 덜 더러워" B: "제일 귀찮은 걸 먼저 끝내야지" | 각자 이유 자막 |
| 14~19초 **반전** | 결판 내려고 세제 짜는 양을 비교하다가, **둘 다 세제를 너무 많이 짜고 있었음**이 드러남 | "...근데 우리 둘 다 이거 틀렸네" |
| 19~25초 **결말** | 화면에 투표 스티커: "컵 먼저 🥛 vs 팬 먼저 🍳" | "정답은 댓글이 정해주세요" |

- **훅 = 인지부조화**: 같은 공간에서 정반대 행동을 나란히 붙여 "누가 맞지?"를 바로 만듦.
- **결말 = 클리프행어**: 정답을 주지 않고 시청자 투표로 끝냄 → 댓글이 결말이 됨. 다음 편에서 "투표 결과" 회수.
- **반전**: 싸움인 줄 알았는데 둘 다 같은 실수. 갈등을 공감으로 바꿔 성별 갈등 댓글을 피함. 실수는 "세제 과다" 수준으로, 위생 문제는 아님.
- **댓글·CTA**: "너네 집은 뭐 먼저?" / "같이 사는 사람한테 보내서 물어보기"
- **협찬 연결**: 세제·수세미·설거지 거치대

## EP.03 사지 마세요: 좁은 조리대에 큰 에어프라이어 `B. 솔직 판정`
**[근거]** 해외 #deinfluencing 1.5억 회 이상, 소개팁의 "직접 써본 것만 추천" 원칙

**첫 화면 자막:** "좁은 주방에 이거 사지 마세요"
**카피 기술:** 금지형

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 위에서 찍은 조리대: 큰 에어프라이어가 조리대를 **다 덮어서** 도마 놓을 자리가 없음 | 탕탕 "15평 회의, 시작합니다" / 자막: "좁은 주방에 이거 사지 마세요" |
| 3~14초 **시연** | 줄자로 조리대 폭 vs 기기 크기 측정, 열기 때문에 상부장과 띄워야 하는 거리, 바스켓 설거지 시간 측정 | 숫자 자막 (실측값) |
| 14~19초 **반전** | 버리려고 들었는데 옆사람: "근데 너 이걸로 매일 고구마 굽잖아" | 사용 횟수 체크 달력: 거의 매일 사용 |
| 19~26초 **결말** | 판정: **"제품은 남김, 크기는 버림"** → 같은 기능의 더 작은 제품과 나란히 놓고 크기 비교 | "15평엔 이 사이즈" + 컵 두 개 소리 |

- **훅 = 시각적 충격**: 조리대가 가전으로 꽉 찬 탑뷰 한 장으로 문제가 바로 이해됨.
- **결말 = 카타르시스**: 무조건 비추천이 아니라 "크기"라는 진짜 원인을 짚어 해결. 솔직하지만 브랜드를 공격하지 않는 판정이라 이후 소형가전 협찬으로 이어짐.
- **반전**: "버림"인 줄 알았는데 사실 제일 많이 씀. 판정이 뒤집히면서 끝까지 보게 됨.
- **댓글·CTA**: "여러분 주방에서 제일 자리 차지하는 가전은?" / **"사이즈" 댓글 → 비교한 제품 정보 DM**
- **협찬 연결**: 소형 에어프라이어·소형가전 (이 회차가 협찬 제안서의 "판정 예시"가 됨)

## EP.04 3구, 20분, 1만 원으로 둘이 저녁 `D. 3구 챌린지`
**[근거]** 김생못 「라면 하나로 삼시세끼」 940만 회, 욜로리아 「만원으로 일주일 반찬」 470만 회, 지현꿍류 "그릇 어디 거예요?" 댓글이 커머스로 이어지는 구조

**첫 화면 자막:** "3구, 20분, 1만 원. 둘이 저녁"
**카피 기술:** 숫자와 구체성 (제약 3개)

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 팬 위에서 치즈가 늘어나는 클로즈업 1초 → 바로 장바구니 영수증 | 지글 소리 / 자막: "3구, 20분, 1만 원. 둘이 저녁" |
| 3~15초 | 탕탕 "15평 회의…" 생략, 대신 타이머 20:00 시작. 3구 전부 동시 가동, 좁은 조리대에서 두 사람 손이 교대로 | 실제 대화: "불 하나 줘" "기다려" |
| 15~19초 **반전** | 계산해보니 **10,800원**, 800원 초과 | "...실패?" → 옆사람이 냉장고에서 남은 대파를 꺼내 재료 하나 빼고 대체 → 9,700원 |
| 19~26초 **결말** | 0~3초와 같은 치즈 클로즈업, 같은 각도 + 영수증 위에 "9,700원 / 19분 42초" 도장 | 컵 두 개 소리 |

- **훅 = 시각적 충격**: 첫 1~2초에 가장 자극적인 조리 장면을 두라는 요리 쇼츠 크리에이터의 경험칙을 그대로 적용.
- **결말 = 미러링**: 같은 장면이지만, 과정을 본 뒤에는 "제약 안에서 해냈다"로 다르게 읽힘.
- **반전**: 예산 초과 → 남은 재료로 해결. 음식 낭비가 아니라 **남은 재료 활용**이라 반감 없이 공감.
- **댓글·CTA**: "다음 챌린지 금액 정해주세요" / 팬·그릇은 로고가 보이게 자연 노출 → **"팬" 댓글 → 제품 정보 DM**
- **협찬 연결**: 프라이팬·냄비·식재료·밀키트 (금액 제한 챌린지는 식품 브랜드 협찬에 그대로 쓰임)
- **큐레이터 링크**: 장보기 재료 → 쿠팡, 팬·그릇 → 29CM·오늘의집

## EP.05 평일 5일 동안 안 치운 15평 `E. 현실 리셋`

|---|---|---|

| 3~16초 | 1시간 타이머 배속. 둘이 구역을 나눔: 한 명은 주방, 한 명은 거실. 로봇청소기 출발 | 실제 대화: "택배 상자 누가 버려?" "가위바위보" |

## EP.06 수건 접는 법, 우리 집은 반반 `C. 우리 집은 이렇게 해`
**[근거]** 집마다 다른 살림 방식이 비교 댓글을 부른다는 식기세척기 논쟁 사례, Couple Joy 밸런스 게임의 저장 효과

**첫 화면 자막:** "3단 접기 vs 돌돌 말기, 15평 수납장에 직접 넣어봄"
**카피 기술:** 숫자와 구체성 + 직접 실험

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 같은 수건을 두 손이 동시에, 하나는 3단으로 하나는 돌돌 | 탕탕 "15평 회의, 시작합니다" / 첫 자막 |
| 3~14초 **시연** | 같은 수납 칸에 각자 방식으로 끝까지 채우기, 장수 세기 | 실측 장수 자막 |
| 14~19초 **반전** | 장수로는 한쪽이 이겼는데, 꺼낼 때 **나머지가 다 무너짐** | "...꺼내는 건 생각 안 했네" |

## EP.08 프라이팬 1주일, 계란으로만 판정 `B. 솔직 판정`

## EP.10 15평 회의: 이번 달 살 것 딱 1개 `E. 15평 회의`
**[근거]** Couple Joy 밸런스 게임(저장 8천 회), 쑤의 시리즈 후속 구조, 브랜드가 보는 "댓글의 질"(제품 질문이 오가는 댓글)

**첫 화면 자막:** "15평이라 한 달에 딱 1개만 삽니다"
**카피 기술:** 숫자와 구체성 + 스토리텔링 (좁은 집이라 생긴 우리만의 규칙)

| 구간 | 화면 | 소리 / 자막 |
|---|---|---|
| 0~3초 **훅** | 식탁 위 후보 카드 3장, 도마를 판사봉처럼 "탕탕" | "15평 회의, 시작합니다" / 첫 자막 |
| 3~14초 | 각자 후보 발표 (실제 대화). A: 무선 청소기 B: 식기건조대 + 이유 | 후보별 자막 |
| 14~19초 **반전** | 따져보니 둘 다 **"주방 바닥이 늘 지저분하다"**는 같은 문제를 풀려고 고른 것 | "...우리 같은 걸 고민하고 있었네" |
| 19~25초 **결말** | 후보 2개를 나란히 놓고 화면에 투표 스티커 | "여러분이 정해주세요. 다음 회의에서 사용기 공개" |

- **훅 = 인지부조화**: 판사봉과 식탁, 회의와 장보기라는 어울리지 않는 조합.
- **결말 = 클리프행어**: 시청자 투표로 다음 구매를 정하고 사용기를 예고 → 팔로우 이유 + 다음 편 조회수 확보.
- **반전**: 의견이 달랐는데 사실 같은 문제를 보고 있었음. 관계를 말하지 않고도 "같이 사는 사람"의 호흡을 보여줌.
- **댓글·CTA**: 투표 댓글 + "추천 제품 있으면 댓글로" → 제품 질문이 오가는 댓글이 쌓여 미디어킷의 "댓글 질" 근거가 됨
- **협찬 연결**: **매달 반복되는 협찬 슬롯**. 2단계(5천 명) 이후 브랜드가 "후보"로 들어오는 형식으로 제안 가능
