# 썸네일 기획자: EP.01 썸네일 3안 (2026-11-17)

- **확정 제목:** 15평에 둘이 삽니다 | 자취 3년 짐 + 남자친구 짐 합친 집
- **옆사람 출연:** 동의 받음 (대표 확인)

## 사전조사
- 조회수 급상승 영상 썸네일 500개 중 69%가 사람 얼굴 (상위 50개는 80%). 과장된 표정은 약 5%뿐 → **또렷한 얼굴 > 과장된 표정** [1]
- 구독자 10만+ 채널 썸네일 11,223개 분석: 놀란 표정은 11%, 한 가지 요소가 우승을 결정하지 않음 [2]
- 글자 있는 급상승 썸네일은 평균 6.8단어, 7단어 이상은 성과가 약간 떨어짐 [3] → 큰 글자 8자 안쪽 규칙과 맞음
- 색 대비는 성과 차이와 뚜렷한 연관이 없었음 [1][3]
- 모두 상관관계 분석이고 도구 회사 자료라 인과 검증은 아님. 자취남·유부남 썸네일을 직접 분석한 자료는 못 찾음 (미확인)

## 3안
| | A. 비포·애프터 | B. 누구 짐이 더 많게 | C. 디자이너의 15평 |
|---|---|---|---|
| **큰 글자** | **이게 다 들어가?** | **누구 짐이 더 많게** | **둘이면 좁아?** |
| 제목과 관계 | 제목은 "합친 집", 글자는 "가능해?" → 결과가 궁금 | 제목은 "합친 집", 글자는 "누구 짐?" → 내기·댓글 유도 | 제목은 "둘이 삽니다", 글자는 "좁아?" → 동거 고민하는 사람의 질문 그대로 |
| 사진 | 왼쪽: 짐을 한데 쌓아둔 거실(옷장·수납장 물건을 실제로 꺼내 쌓아 촬영) / 오른쪽: 정리된 같은 앵글 | 화면 가운데를 나눠 왼쪽엔 옆사람 짐 더미, 오른쪽엔 내 짐(모니터·태블릿·작업 장비) | 거실 정면 사진 + 그 위에 모션디자이너다운 평면도 선과 치수 그래픽 "15평 ≈ 49.6㎡" |
| 사람·표정 | 짐 더미 사이에서 둘이 서로 쳐다보는 자연스러운 "어떡하지" 표정 | 각자 자기 짐 앞에서 서로를 가리키며 웃는 얼굴 | 소파에 나란히 앉은 둘, 편안한 미소 (작게) |
| 색 | 크림 배경 글자 박스 + 딥그린 글자, 비포→애프터 노란 화살표 | 왼쪽 딥그린 / 오른쪽 아이보리 (시그니처 컵 캐릭터 코드) + 검정 글자 | 사진 원색 + 흰 선 그래픽 + 딥그린 글자 박스 |
| 배치 | 좌우 분할, 큰 글자는 위 가운데 | 세로 분할, 큰 글자는 아래 가운데 | 사진 전체, 큰 글자는 왼쪽 위, 치수 그래픽은 오른쪽 |
| 노리는 효과 | 자이가르니크 (결과를 보고 싶음) | 인지부조화 + 댓글 내기 | 브랜딩 (디자이너 채널임을 썸네일부터) |

## 추천
- **메인: A** — 결과를 숨겨서 클릭을 부르고, 영상 내용(짐 합치기)과 정확히 일치. 얼굴 + 짧은 글자로 조사 결과와도 맞음
- **B**는 두 사람 캐릭터와 컵 색 코드를 처음 소개하는 효과가 커서 2위
- **C**는 채널 정체성용. 이후 시리즈 공통 틀(평면도 그래픽)로 쓰기 좋음
- 유튜브 스튜디오의 썸네일 테스트 기능(최대 3개 비교)이 계정에서 열려 있다면 **A·B·C를 모두 올려 유튜브가 고르게** 하는 것도 방법

## 촬영 체크
- A 비포 사진: 실제 물건을 꺼내 쌓아서 찍기 (연출 과장 금지)
- 얼굴은 또렷하게, 과장 표정 X
- 썸네일용 사진은 영상 촬영 날 같이 찍기 (가로 16:9, 인물은 화면 1/3 이상)
