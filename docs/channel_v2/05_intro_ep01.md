# 도입부 작가: EP.01 첫 30초 대본 3안 (2026-11-20)

- **제목:** 15평에 둘이 삽니다 | 자취 3년 짐 + 남자친구 짐 합친 집
- **썸네일:** A "이게 다 들어가?" (짐 정리 전후 비교) — 확정
- **끝까지 보면 얻는 것 (제안):** 두 사람 짐을 합칠 때 실제로 부딪히는 3가지와 우리가 찾은 타협
  1. 공간: 내 작업용 컴퓨터 vs 옆사람의 큰 TV
  2. 소비: 가성비파 vs 비싸도 예쁜 거 파 (아직도 부딪히는 중)
  3. 못 버리는 옷 (3개월째 비우는 중)
  + 이사 후 제일 좋아진 곳: 부엌 (음식물 처리기·오븐·3구)

## 대표가 들려준 실제 경험
- 이사 날 두 집 짐이 한 번에 들어와 **한 달간 짐에 둘러싸여** 지냄
- 3개월 지난 지금도 **점점 비워나가는 중**. 서로 옷을 못 버리고, 필요한 물건도 아직 다 못 삼
- 나는 작업 때문에 **컴퓨터 필수**, 오빠는 힐링용 **엄청 큰 TV를 절대 못 버림** → 공간 배치가 어려웠음
- 오빠는 **가성비**, 나는 **비싸도 예쁜 것** → 아직도 부딪히는 중
- 가장 좋아하는 곳은 침대, 이사 후 **더 좋아진 곳은 부엌** (원룸보다 넓진 않아도 음식물 처리기·오븐 설치 가능, 하이라이트 3구)

## 사전조사
- 유튜브 공식: 인트로(첫 30초) 지표가 높다는 건 첫 30초가 **제목·썸네일에서 본 기대와 맞았다**는 뜻일 수 있음 [1] → 썸네일 "이게 다 들어가?"의 약속을 첫 30초에 바로 꺼낼 것
- vidIQ: 롱폼에서 좋은 지속률은 30초 지점에 시청자 60% 이상 유지 (2026.6까지 12개월 데이터) [2]
- 인사 없이 내용부터, 하이라이트를 먼저 보여주는 방식 권장 [3] (출처 미상 수치 포함, 참고용)

## 3안 (각 약 30초, 인사·자기소개 없음)

### 1안. "아직 비우는 중" — 자이가르니크 (추천)
| 화면 | 대사 |
|---|---|
| 짐 더미 (썸네일 A의 정리 전 컷) | 자취하던 짐, 같이 살 집에 다 들어갈까요? |
| 같은 앵글 유지 | 저희는 안 들어갔어요. |
| 이삿날 사진·영상 (있으면) | 이사한 날 두 집 짐이 한 번에 들어와서, 한 달을 박스에 둘러싸여 살았거든요. |
| 지금 집 구석에 남은 박스 클로즈업 | 그리고 3개월이 지난 지금도… 아직 비우는 중이에요. |
| 15평 평면도 모션그래픽, 짐 아이콘 두 묶음이 합쳐짐 | 오늘은 15평에 두 사람 짐을 합치면서 진짜로 부딪힌 세 가지랑, 저희가 찾은 타협을 보여드릴게요. |
| 부엌을 살짝만 (흐리게) | 마지막엔 이사하고 제일 좋아진 곳도요. |

- 첫 문장이 썸네일 질문을 그대로 받음 → 기대와 첫 30초가 일치
- "아직 비우는 중"이라는 미완성 상태가 끝까지 보게 만듦
- 결말은 미러링: 첫 장면과 같은 앵글에서 지금의 집으로 끝냄

### 2안. "싸움의 원인은 TV" — 인지부조화
| 화면 | 대사 |
|---|---|
| 큰 TV와 작업용 컴퓨터를 번갈아 컷 | 같이 살면 제일 먼저 부딪히는 건 뭘까요. |
| TV 정면 | 저희는 돈도 집안일도 아니고, TV였어요. |
| 모니터 앞 작업하는 손 | 저는 일 때문에 컴퓨터가 꼭 있어야 하고, |
| 리모컨 쥔 옆사람 손 | 오빠는 힐링하려면 이 큰 TV는 절대 못 버린대요. |
| 15평 평면도에 TV·책상 아이콘이 서로 밀어냄 | 15평에 둘 다 들어가야 하는데… 결론부터 말하면, 둘 다 남았어요. |
| 아직 남은 박스 | 어떻게 넣었는지, 아직도 해결 못 한 것까지 다 보여드릴게요. |

- "돈·집안일이 아니라 TV"라는 예상 밖 요소로 시작
- 썸네일 "이게 다 들어가?"와도 이어짐 (TV가 들어가나?)

### 3안. "동거 앞두고 있다면" — 타겟 지목 + 손해 짚기
| 화면 | 대사 |
|---|---|
| 짐 더미 | 동거 앞두고 있다면 이것부터 보세요. |
| 박스 사이를 지나가는 발 | 짐을 합치기 전에 정했어야 할 게 있었는데, 저희는 몰라서 한 달을 박스 사이에서 살았어요. |
| 장바구니 두 개: 가성비 물건 vs 예쁜 물건 | 가성비파랑 예쁜 거 사는 파가 같이 살면 어떻게 되는지도요. |
| 지금 집 전경 | 3개월째 같이 사는 15평 집에서, 저희가 미리 알았으면 좋았을 세 가지를 정리했어요. |

- 동거 고민 중인 사람(메인 시청자)을 바로 부름
- 단, 썸네일 질문과는 1·2안보다 덜 직접적
