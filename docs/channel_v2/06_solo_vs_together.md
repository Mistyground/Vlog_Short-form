# 혼자 vs 같이 비교 + 공구 관점 (2026-11-20)

대표 질문: "동거 키워드를 꼭 넣으려는 기준이야, 혼자와 같이를 비교해서 판단한 거야? 공구도 많이 받고 싶어."

## 솔직한 답
- 동거는 처음부터 정해둔 키워드가 아니었음. 시청자 니즈·주제 리서치에서 "수요는 큰데 다루는 채널이 적다"는 근거로 들어감
- 하지만 **혼자 vs 같이를 같은 기준으로 나란히 비교하지는 않았음.** 이전 15평회의(두 사람) 기획의 흐름도 영향을 줬을 수 있음 → 아래에서 다시 비교

- 혼수 평균 1,445만 원, 침대·냉장고·청소기 같은 오래 쓰는 품목엔 지출을 아끼지 않음 (듀오 2026 결혼비용 실태 보고서) [1]

## 비교표
| 기준 | 혼자 (모션디자이너 나) | 같이 (동거) |
|---|---|---|
| 차별성 | 직장인 브이로그는 포화. 단 "광고 모션디자이너"는 빈 시장 | 일반인 동거 채널 적음. 상위권은 예능·몰카형이 많아 진솔한 정보형은 비어 있음 |
| 조회수 근거 | 디자이너 일상 579만, 작업 셋업 263만, 퇴사 이야기 195만 | 동거일기 ep.1 121만, 동거 Q&A 구독자 대비 5.7배 |
| **공구 적합도** | 데스크 셋업·작업 장비·문구·뷰티 (공구 빈도 미확인) | **살림 장만 단계**의 시청자 → 가전·침구·주방·수납. 혼수 1,445만 원 시장과 직결 |
| 나만의 브랜딩 | 강함 | 중간 (둘의 이야기로 읽힘) |
| 오래 가는 힘 | 강함 | 관계 변화에 취약 |
| 제작 부담 | 혼자 촬영 가능 | 옆사람 시간 필요 |

## 결론: 주인공은 "나", 동거는 "지금 내 삶의 무대"
방향 C는 유지하되 비중을 분명히 함.
| 비중 | 콘텐츠 | 역할 |
|---|---|---|
| 50% | **나**: 모션디자이너의 일·작업·도전("해보는 사람") | 브랜딩, 오래 가는 축 |
| 30% | **둘살림**: 살림·가전·소비 취향 | **공구의 핵심** |
| 20% | **15평 공간**: 배치·수납·인테리어 | 검색 유입, 쇼츠 |

### 공구 전략 아이디어: "가성비파 vs 예쁜파 둘 다 통과한 물건만"
- 대표(비싸도 예쁜 것)와 옆사람(가성비)의 실제 소비 성향 차이를 그대로 **검증 장치**로 씀
- 한 사람 취향만 통과한 물건은 소개만 하고, **둘 다 통과해야 "남김템" → 공구 후보**
- 시청자 입장에선 "가성비도 디자인도 둘 다 확인된 물건"이라 신뢰가 생김 (브랜드가 보는 제품-크리에이터 궁합과도 맞음)
- 첫 시작은 EP.01의 "소비 취향 충돌" 챕터에서 자연스럽게 예고

### 인스타 공구 계정 (커플 5 vs 1인 5)
| 항목 | 커플·신혼 | 1인 |
|---|---|---|
| 팔로워 | 6,692 ~ 12.7만 (4개가 2만 미만) | 8.9만 ~ 33.1만 |
| 릴스 평균 ÷ 팔로워 | **1.0 ~ 5.8배 (모두 1배 이상)** | 0.11 ~ 1.3배 (4개가 1배 미만) |
| 최근 릴스 10개 중 공구 | 2 ~ 5개 | 2 ~ 10개 |
| 댓글 질문 | **"우리 집에 맞나"** (사이즈, 좁은 공간) | 제품 사양 (전기세, 수량) |
| 신뢰 방식 | "우리 집에서 써봄" + 관계 서사 | 전문성 |
- 예: 소소한집(신혼, 10평 행복주택) 팔로워 1.7만에 릴스 평균 84,840 (5.0배), 미니홈 1.5만에 86,486 (5.8배)
- 공통 구조: 댓글 키워드 → DM 링크 / 예고 → 오픈 → 마감을 각각 콘텐츠로 / 가격 근거를 숫자로 / 구매완료 이벤트로 후기 수집 / 품목은 주방·수납·침구·계절가전
- 공구 매출·수수료는 미확인

### 유튜브
- **"신혼집 집들이"는 상위 10개가 모두 구독자 32만 이상 채널** (배수 0.6~2.6배) → 새 채널이 정면으로 붙기 어려움
- **배수 상위는 소형 채널의 "현실 고백형"**: 「패션디자이너의 입사 후 한달만에 퇴사」 281배, 「MZ 대기업 3번 퇴사한 진짜 이유」 85.5배, 「6개월 차 엔터 직장인 브이로그」 52.7배, 「월 190 신입 직장인」 46.1배, 「freelance 3D artist」 24.2배

### 기획 반영
1. **둘살림·15평 이야기는 인스타 릴스·쇼츠에서 퍼지는 힘이 큼** → 쇼츠·릴스의 중심은 둘살림과 15평
2. **유튜브 롱폼 훅은 "직업 현실 고백" + "15평 동거"를 겹치기** → 집들이 단독 제목은 대형 채널과 경쟁
3. **공구 운영 기준 (비교 커플 계정 범위)**: 처음엔 월 2~4회, 릴스 10개 중 3~4개 이하. 차별점은 "15평에 맞는지 검증" + "가성비파 vs 예쁜파 둘 다 통과"
4. EP.01 제목은 집들이형 → 직업 현실을 앞에 붙이는 수정안 검토 (대표 결정)
