## 1. 프로필 이미지 추천

### 사전조사
- 인지도가 없는 상태에서 로고만 올리면 방문자에게 "의미 없는 도형"처럼 보일 수 있으니, 처음에는 **업종을 바로 알 수 있는 사진**을 쓰고 로고는 인지도가 쌓인 뒤 넣으라는 실무 조언 [1]
- 프로필 이미지는 작은 크기로 표시되므로 작게 봐도 알아볼 수 있어야 함 [2]
- 프로필 사진·이름·소개·링크·하이라이트가 하나의 흐름으로 이어져야 팔로우로 이어진다는 조언 [1]
- 한계: 성공 계정들의 프로필 이미지를 직접 비교한 공개 자료는 찾지 못함 (미확인)

### 추천안: "탕탕 세트" 실사 탑뷰
```
나무 도마 (가운데)
 ├─ 나무 주걱 1개 (대각선, "탕탕" 시그니처)
 └─ 머그 두 개 (엔딩 "컵 두 개" 시그니처)
배경: 따뜻한 단색 (크림·베이지·연한 테라코타 중 하나)
```
| 기준 | 이 안이 맞는 이유 |
|---|---|
| 업종이 보이나 | 도마·주걱·머그 = 주방·살림 계정이 한눈에 |
| 세계관과 연결되나 | 오프닝 "탕탕"(주걱+도마), 엔딩 "컵 두 개"가 프로필에 그대로 → 영상을 본 사람이 프로필에서 다시 알아봄 |
| 관계 노출 | 얼굴 없이 "둘이 사는 집"을 머그 두 개로만 암시 |
| 작은 원형에서 | 물건 3개 이하, 단색 배경이라 작게 봐도 형태가 보임 |

### 촬영 팁
- 위에서 수직으로(탑뷰), 자연광 오전, 그림자 약하게
- 원형으로 잘리므로 물건은 **가운데 70% 안**에
- 머그는 실제 영상에 나오는 그 머그 (EP.10 "처음 맞춘 머그"와 연결)
- 인스타·유튜브·틱톡 **같은 이미지**로 통일
- 팔로워 1만 명 이후: 같은 구도를 단순한 일러스트 로고로 바꿔 굿즈·공구 패키지에도 쓰는 것 검토

## 2. 상표 출원

### 사전조사
- 유튜브 채널 관련 상표 분쟁이 늘고 있고, 핵심은 **먼저 출원하는 것** [3]
- 사례: '신사임당' 채널은 2018년 개설 후 늦게 출원했고, 그 사이 제3자가 35류(광고업)·38류로 먼저 출원 [3]
- 유튜브 채널 운영은 보통 **41류**(연예오락업, 인터넷 동영상 제공업)로 알려져 있음 [4]
- 비용 (특허로 전자출원 기준, 출처마다 차이 있음)
  - 출원료: 1류당 46,000원 [5] 또는 62,000원 [6]
  - 등록료: 1류당 201,000원 (2025.1.1 시행 기준, 2회 분할 납부 가능) [5]

## 3. 시그니처 "컵 두 개" 스펙 (2026-11-12, #8)

### 사전조사
- 짝 맞춘 커플 머그는 "우리"라는 정체성을 드러내는 상징이지만 지난 시대의 스타일이라는 시각, 짝 안 맞는 머그 모음이 더 "진짜 생활" 같다는 시각이 있음 [7]
- 두 사람은 마시는 방식(양·온도)이 달라 같은 머그가 꼭 맞지 않는다는 실용적 지적 [8]
- 브랜딩 칼럼: 보면 바로 그 브랜드가 떠오르는 "시그니처" 하나, 등장할 때마다 같은 요소를 반복하는 일관성이 기억에 남음 [9][10]
- 한계: 시그니처 소품의 효과를 실증한 자료, 오늘의집 머그 인기 순위 집계는 찾지 못함 (미확인)

### 추천: "짝이 안 맞는 두 컵" → 시간이 지나며 맞춰지는 서사
| 시기 | 컵 | 의미 |
|---|---|---|
| 지금 ~ 100일 | **서로 다른 두 컵** (각자 원래 쓰던 컵 느낌) | "우리 집은 이렇게 해" = 둘의 차이가 계정 콘셉트. 커플 티가 안 나서 관계 노출 원칙에도 맞음 |
| EP.10 (100일) | 같은 디자인, 다른 색 머그로 교체 | "가장 많이 바뀐 건 컵" 반전 (이미 대본에 있음) |
| 결혼 발표 | 같은 디자인, 같은 색 | 미러링: 컵이 완전히 맞춰지는 순간 = 발표 |

### 지금 쓸 두 컵 조건
- **색 대비**: 하나는 진한 색(딥그린·테라코타·네이비), 하나는 밝은 색(아이보리·크림). 작은 원형 프로필에서도 "두 개"로 보임
- **음료도 대비**: 한 잔은 블랙커피, 한 잔은 라떼·우유 → 위에서 보면 진한 원 + 밝은 원. "취향이 다른 두 사람"이 말없이 전달됨
- **손잡이 방향**: 탑뷰에서 손잡이가 서로 마주 보게(안쪽으로) → 관계를 말하지 않고 "같이"를 암시
- **재질: 세라믹 머그** — 내려놓을 때 "톡" 소리가 매 회 같은 시그니처 사운드가 됨 (유리·스테인리스는 소리가 다름)
- **피할 것**: 커플 문구·이니셜·하트·Mr&Mrs 류(관계 노출), 브랜드 로고(협찬 충돌), 흰 컵+흰 배경(작은 화면에서 안 보임)
- **실용**: 매 영상에 나오므로 식세기·전자레인지 가능, 깨지면 같은 걸 다시 살 수 있는 제품. 나중에 "15평회의 머그" 굿즈·공구로 이어질 수 있음

## 4. 컵 시안 검토 결과 (2026-11-12, #9)
대표 시안: 딥그린 머그(아이스 아메리카노) + 아이보리 머그(블루베리 스무디), 우드 테이블, 3/4 각도.

| 항목 | 판정 |
|---|---|
| 색 대비·로고 없는 세라믹 | ✅ 스펙 그대로 |
| 음료 대비 | ✅ 44px 크기에서 보라색이 가장 먼저 보임 |
| 작은 원형 식별 (320/110/44px 테스트) | ✅ 통과 |
| 각도 | ✅ 3/4 각도가 탑뷰보다 나음(머그 몸통 색이 보임) → **기존 "탑뷰" 제안 변경** |
| 손잡이 | ⚠️ 바깥쪽 → 안쪽(마주 보게)으로 |
| 구도 | ⚠️ 컵을 가운데로, 원의 70% 크기 |
| 바짝 크롭 | ❌ 초록 컵이 잘림 |

- 프로필은 **도마·주걱 없이 컵 두 개만** (물건이 늘면 컵이 작아짐. 도마·주걱 "탕탕"은 영상 오프닝 담당)
- 제안: 컵 = 캐릭터 코드. 초록 컵 사람 / 아이보리 컵 사람으로 얼굴 없이 두 사람 구분 → C 시리즈에서 "초록팀 vs 아이보리팀" 투표

## 5. 시안 2 검토: "우리 집 컵이 아님" (2026-11-12, #10)
대표 시안 2: 줄무늬(초록·테라코타·남색) 핸드메이드 머그 + 아이보리 투톤 머그, 베이지 배경, 손잡이 안쪽.

| 항목 | 시안 1 | 시안 2 |
|---|---|---|
| 구도·크기 | 컵이 아래쪽·작음 | ✅ 가운데·큼 |
| 손잡이 | 바깥쪽 | ✅ 안쪽, 맞닿음 |
| 작게 봤을 때 색 | ✅ 초록이 분명 | ❌ 줄무늬가 남색 덩어리로 보임 |
| 배경 대비 | ✅ 우드가 아이보리를 살림 | ❌ 베이지에 아이보리가 묻힘 |

### 결정: 실제 집에 있는 컵만 쓴다
- 프로필 컵과 영상 속 컵이 다르면 시그니처가 성립하지 않음
- 이 계정의 핵심은 "진짜 생활·솔직 판정". AI로 만든 정보·리뷰는 브랜드 신뢰를 떨어뜨린다는 조사 [11]. Meta는 AI 생성 지표가 감지되면 게시물에 'AI 정보' 라벨을 붙임 [12]
- 시안 1·2는 **레퍼런스**로만: 시안 1의 색(단색 진한 컵 + 아이보리, 우드 배경) + 시안 2의 구도(가운데, 손잡이 안쪽)

### 다음 단계
1. 집에 있는 컵을 전부 꺼내 한 장에 찍어 공유 → 크롭 테스트로 두 개 고르기
2. 맞는 컵이 없으면 **컵 고르기 자체를 콘텐츠로**: "15평 회의: 우리 집 시그니처 컵 정하기" (E 시리즈, 참관인 투표, 오늘의집 링크)
