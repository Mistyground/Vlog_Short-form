## 1. 토론 요약

### 쟁점 ① 기존 1위 "집이되는중"을 유지할까?
| 참가자 | 입장 | 핵심 근거 |
|---|---|---|
| 트렌드 리서처 | **반대** | 크게 터진 작은 집 콘텐츠는 제목에 숫자가 고정돼 있었음(「두명이 사는 원룸」 583만 회 등). "집이되는중"엔 숫자·공간·콘셉트가 없음. 오프닝 "15평 회의, 시작합니다"와 이름이 달라 기억이 둘로 갈라짐 |
| 커머스·협찬 리서처 | **조건부 반대** | 브랜드 담당자가 이름만 보고 "무엇을 어떻게 다뤄주는 계정인지" 알 수 없음. "becoming home"은 흔한 영어 표현이라 상표·검색에서 불리할 수 있음(추정) |
| 커뮤니티 분석가 | **반대** | "집이되는중님"은 댓글에서 부르기 어려움. 콘셉트 단어("회의록 올려주세요", "안건 있습니다")가 댓글 놀이가 됨 |

**→ 판정: 만장일치로 "집이되는중" 탈락.** 이 이름은 "15평 회의" 콘셉트가 나오기 전의 추천이었고, 지금은 오프닝·시리즈·계정명이 같은 말이어야 반복 노출이 브랜드로 쌓인다는 주장이 타당합니다.

### 쟁점 ② 숫자 "15평"을 이름에 넣으면 이사할 때 곤란하지 않나?
- 트렌드 리서처: 이사하면 "○○평회의"로 **시즌을 바꾸면 됨**. 오히려 "평수 변경 안건"이 큰 콘텐츠가 됨
- 커머스 리서처: 같은 의견. 평수 변경 자체가 이벤트
- 커뮤니티 분석가: 약점은 맞지만 콘셉트 단어가 주는 이점이 더 큼

**→ 판정: 숫자 유지.** 확장성 손해보다 검색·첫인상 이득이 큼. 이사는 시즌 전환으로 처리.

### 쟁점 ③ 큐레이터 링크 5곳을 처음부터 다 운영할까?
- 커머스 리서처: **반대.** 초기에 링크가 5곳으로 나뉘면 브랜드에 보여줄 판매 실적이 흩어지고, "어디서든 파는 계정"처럼 보여 솔직 판정 신뢰를 깎음

**→ 판정: 수용.** 가입은 미리 해두되(무료), **콘텐츠에 거는 링크는 단계적으로 늘린다.** (아래 4장)

### 쟁점 ④ 결혼 발표 회차
- 커뮤니티 분석가: 관계를 숨긴 것보다 **"처음부터 결혼으로 돈 벌려던 것 아니냐"**는 의심이 더 위험. 발표 회차에는 협찬을 넣지 말고 1~2회 뒤부터

**→ 판정: 수용.** 결혼 협찬 플랜에 반영.

## 3. 🏆 최종 결정: 이름 하나에 역할 셋

| 역할 | 이름 | 출처 |
|---|---|---|
| **계정명** | **15평회의** | 3명 모두 1순위 |
| **큐레이터 샵·공구 이름** | **남김템** ("15평회의 통과템") | 커머스·트렌드 리서처 |
| **댓글 밈·시청자 호칭** | 오프닝 효과음 **"탕탕"** / 시청자 = **"참관인"** | 커뮤니티 분석가 |

### 세팅
```
핸들:      @15pyeong.meeting   (선점 실패 시 → @15py.meeting → @pyeong15.meeting)
이름 필드:  15평회의 | 둘이 사는 오피스텔 살림
소개:      15평에 둘이 사는 진짜 집 🏠
           써보고 솔직 판정 · 회의 통과한 남김템만 🛒
           📩 협찬/광고 문의 DM
```
- 이름 필드에 "오피스텔 살림" 같은 키워드를 덧붙이는 이유: 인스타 이름 필드는 검색에 걸리는 것으로 알려져 있음 (트렌드 리서처, 일반 지식)
- 핸들 앞이 숫자라 직접 입력은 조금 불편함 → 영상 엔딩과 프로필에 핸들을 자주 노출

### 이름이 만드는 세계관
| 장면 | 쓰는 말 |
|---|---|
| 매 회 오프닝 | 주걱 "탕탕" + "15평 회의, 시작합니다" |
| 시청자 댓글 | "안건 하나 올립니다", "이 결정 재심 요청합니다", "회의록 올려주세요" |
| 솔직 판정 | "회의 통과 → 남김템" / "부결 → 버림" |
| 큐레이터 샵 | "15평회의 남김템 장바구니" |
| 공구 | "공구 안건 #3" |
| 이사할 때 | "평수 변경 안건" → 시즌 2 "○○평회의" |
| 결혼 발표 | "제○○차 15평 회의 특별 안건: 혼인의 건 → 가결" (협찬 없이) |
| 결혼 후 | "혼수 분과위원회" 시리즈 |

## 4. 큐레이터 링크 단계적 운영 (쟁점 ③ 반영)
| 단계 | 콘텐츠에 거는 링크 | 이유 |

| 0 → 1천 | **쿠팡 + 오늘의집** | 3구 주방템·생활 소모품은 쿠팡과 겹치는 범위가 넓고, 오늘의집은 인테리어 협찬 포트폴리오가 됨 |
