## 2. 데이터가 말하는 것

### 잘 되는 것
1. **제약을 숫자로 건다**: 평수, 인원, 예산, 화구 수를 제목·첫 화면에 ("두명이 사는 원룸", "만원으로 일주일", "다이소 압축봉 하나로") [1][2][3]
2. **돈 안 드는 해결이 가장 크게 퍼진다**: 가구 배치, 저가템 해킹 [1][2]
3. **무타공 수요는 검증됨**: 오늘의집 2025 검색어 결산에서 무타공 상품이 검색량 상위 1% [10]
4. **"써보니까 이랬어요" > "바뀌었어요"**: 해외 #deinfluencing(사지 마세요) 영상 1.5억 회 이상 [11]. 국내 대행사도 시연 → 장단점 구조를 추천 [12]
5. **말 대신 시연**: 무게, 눌어붙음, 세척, 한 손 사용. 브랜드도 이 시연 능력을 보고 계정을 고름 [13]
6. **"너네 집은 어떻게 해?"**: 집마다 방식이 다른 살림 행동(설거지, 수건 접기, 냉장고 정리)이 댓글을 가장 많이 부름 [7]
7. **완벽하지 않은 집**: "우리 집도 그래요" 안도 댓글 [14]. 소형 주거 영상 대부분이 미화되어 있어 **실제 생활감은 비어 있는 자리** [15]
8. **얼굴 대신 목소리**: 대화의 티키타카와 반복 멘트가 관계와 캐릭터를 만듦 [4][5]

### 피해야 할 것
| 위험 | 근거 |
|---|---|
| 과장된 before/after 한 방 공개 | 성과 좋은 영상일수록 비포·애프터가 적다는 대행사 분석 [12] |
| 쇼룸 같은 집, 연출 티 | "staged" 비판 사례 [16] |
| 자랑으로 보이는 구성 | `[일반 지식]` → **"자가"는 콘텐츠에서 언급하지 않는다** |
| 음식 낭비·위생 문제로 분노 유도 | 해외 rage bait 비판 확산 [17]. "귀여운 실수"에서 멈출 것 |
| 한쪽을 깎아내리는 성별 갈등 | `[일반 지식]` 댓글 싸움으로 번지고 브랜드가 꺼림 |
| 광고를 '더보기' 안에만 표기 | 공정위 2022년 SNS 부당광고 21,037건 적발, 인스타가 9,510건으로 최다 [18] |

## 3. 수익화와 연결되는 발견
- **브랜드는 팔로워 수보다 "제품-크리에이터 궁합"과 댓글의 질**을 봄 (사이즈·옵션 질문, 이전 후기) [19]
- 매체 기준 예시: 팔로워 1만~15만, 릴스 비중 50% 이상, **팔로워 대비 릴스 조회수 100% 이상** [20]
- 인스타 릴스 캡션 링크는 클릭이 안 됨 → **"댓글 키워드 → DM 자동 링크"**가 공구·제휴의 기본 구조 [21]
- 인스타는 **DM 공유(sends)**, 저장, 시청 시간을 중요하게 본다는 보도가 많음 (가중치는 공식 수치 아님) [22]
- 쇼츠 광고 수익은 작음 (블로그 추정, 미검증) → **제휴·협찬이 핵심** [23]

## 4. 결론: 대본 방향 전환

| 기존 방향 | 새 방향 | 근거 |
|---|---|---|
| 감성 브이로그 + before/after | **현실 15평, 둘이 사는 진짜 생활 + 문제 해결** | 공간베어, 김생못, 미화되지 않은 생활감의 빈자리 |
| 자막만, 내레이션 없음 | **실제 대화 녹음(목소리) + 시그니처 오프닝 멘트** | 인생 녹음 중, 쑤 |
| 판정 도장 엔딩 | **시연으로 증명 → 단점까지 말하는 솔직 판정** | deinfluencing, 소개팁 |
| 정보 전달형 마무리 | **"너네 집은?" 논쟁·투표형 마무리** | 식기세척기 논쟁, 밸런스 게임 |
| 캡션 해시태그 위주 | **댓글 키워드 → DM 링크, "같이 사는 사람한테 보내기"** | 공구 DM 구조, sends 신호 |
